# Linux Masterclass (Proof of Concept)

A beginner-friendly Linux practice POC

## About

This project contains my notes, command practice, and simple Bash scripts created while learning Linux.

The goal is to understand Linux by **learning the concept, practicing it locally, and documenting what I learned**.

## What I Learned

* Linux basics
* Linux terminal and shell
* Files and directories
* File permissions
* Wildcards
* Command history and aliases
* Hard links and symbolic links
* Background jobs and processes
* `nohup`
* Disk usage
* ZIP and TAR
* `wc`, `sort`, `uniq`
* `grep`
* `find`
* `awk`
* SSH and SCP
* Package management
* Cron
* Basic networking
* Bash shell scripting
* Airflow basics
